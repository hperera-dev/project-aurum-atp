# Project AURUM — v3 Cinematic Edition

Cinematic marketing frontend for **Project AURUM** (Group SE-10, IIT Sri Lanka × University of Westminster):
- **Stack:** Next.js 15 (Static Export), TypeScript (Strict), Tailwind CSS v4, GSAP 3 + ScrollTrigger, Lenis, Framer Motion, Three.js PBR 22K Gold Hallmark Ring
- **Visual System:** Posh Ruby Velvet (`#120203` → `#3D090C`), 22K Liquid Bullion Gold (`#F7DFA3`), Liquid Ruby Glass (`feTurbulence` + `feDisplacementMap`), Warm Alabaster contrast chapters

## Commands
```bash
npm install
npm run dev      # http://127.0.0.1:3001
npm run typecheck
npm run build    # Static export to out/
```
