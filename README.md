# 🪙 Project AURUM - The Phygital Gold Traceability Network

**Module:** 5COSC021C Agile Team Project (CW1)  
**Target Market:** Sri Lanka (High-end retail bullion and jewelry)  
**Regulatory Context:** Compliant with NGJA Assay Standards & MUSSD Act No. 35

---

## 📖 Project Overview
Project AURUM links a physical gold item to a persistent digital record using a miniature laser-engraved GS1 DataMatrix code, verified physical measurements, and secure transaction logs. This repository contains the Phase 1 (CW1) deliverables including system architecture, UI/UX high-fidelity prototypes, Agile management records, and the marketing landing page source code.

## 🧑‍💻 Team Roles & Directory Guide
To ensure strict Agile version control and satisfy Learning Outcome 2, all team members commit their respective CW1 assets here via Pull Requests:

* 🌐 **`/landing-page`**: Web source code (Product Owner & Web Lead)
* 🧠 **`/architecture`**: UML, DB Schemas, Parent-Child DAG logic (System Architect)
* 🎨 **`/design-and-ui`**: High-Fidelity Figma exports & Wireframes (UI/UX Lead)
* ⏱️ **`/agile-management`**: Sprint records, Notion board states, Burndown charts (Scrum Master)
* 📊 **`/requirements-and-qa`**: Signed UoW Ethics Form, SRS, Test Strategies (BA / QA Lead)

## 🔀 Strict Git Workflow 
1. **Never commit directly to `main`.** (Branch protection is active).
2. Create a feature branch (e.g., `feature/sprint1-uml-diagrams`).
3. Upload/commit your assets to your designated folder.
4. Open a Pull Request early (use `[WIP]` for drafts).
5. **1 Peer Approval is required** before merging into `main`.
